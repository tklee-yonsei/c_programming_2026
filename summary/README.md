# summary 예제

이 폴더는 C 언어의 핵심 개념을 한 번에 연습할 수 있는 작은 종합 예제입니다.

- 구조체와 배열: 학생 정보를 구조체 배열로 관리
- 포인터: 포인터 인자를 통해 학생 데이터 초기화/평가
- 함수 포인터: 학점 정책 함수, 정렬 비교 함수를 런타임에 교체
- 함수 분리: 역할별 함수로 로직을 나누어 모듈화

## 빌드 및 실행

```bash
make
./summary.out
```

## 예제 시나리오

프로그램은 간단한 학생 성적 요약 과정을 다룹니다.

1. 여러 학생 데이터를 생성합니다.
2. 과목 점수를 배열로 저장합니다.
3. 학점 정책 함수 포인터를 통해 학생별 총점/평균/학점을 계산합니다.
4. 비교 함수 포인터를 바꿔가며 같은 데이터를 다른 기준으로 정렬합니다.
5. 정렬 결과와 정책 변경 결과를 표 형태로 출력합니다.
